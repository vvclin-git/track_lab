# 航跡實驗室｜Windows 本機版

1. 解壓縮到可寫入的資料夾。電腦需有 Python 3.9+ 與 FFmpeg。
2. 如果 FFmpeg 沒加到 PATH，請將 `ffmpeg.exe` 放進本工具的 `bin` 資料夾。
3. 雙擊 `start.cmd`。瀏覽器會開啟 `http://127.0.0.1:8765/`。也可用 `python server.py --port 8766` 指定其他連接埠。
4. 依原本流程匯入航跡與 frame–UTC 表，再到影片設定選影片並綁定配對表。
5. 設定時間工作區，在影片區按「建立航跡預覽」。點航跡點即可查看對應 JPG，或按「跳至影片」回原片。
6. 用 Ctrl+C 結束服務。

預設使用離線航跡圖，可從圖層選單切到線上底圖。程式、航跡分析、影片與預覽都能在本機運作，只有線上底圖需要網路。

首次建立預覽會把影片透過 loopback 串流複製到本機暫存目錄，請預留約一支影片的空間（同一個瀏覽器工作階段中每支影片只需傳一次）。暫存隨服務正常結束清理。JPG 保留在工具下方的 `previews`，以影片內容、容許誤差與播放器時間識別。重開後，重新綁定影片並按建立，即可註冊影片並重用既有 JPG。

FFmpeg 從片頭連續解碼至最後所需時刻，避免對每張 JPG 反覆跳轉。每張圖以播放器時間換算 PTS，並核對 FFmpeg 實際輸出的 PTS，在「影片設定」可調整預覽 PTS 容許誤差（1–250 ms，預設 25 ms）。程式選擇範圍內最接近的一格，距離相同時取較早的一格。偏差超過 1 ms 時會標記近似與早晚差值，找不到候選則列為缺少。更改容許誤差後請重新建立航跡預覽。舊版預覽需重新建立一次，才能附上實際 PTS。裁切影片請如實填寫片段的原片起始影格及其播放器秒數。

工具使用原有瀏覽器播放器，原片逐格跳轉速度仍取決於影片編碼和關鍵影格間隔。FFmpeg 用於批次擷取 JPG。工具不會把影片送出本機。
